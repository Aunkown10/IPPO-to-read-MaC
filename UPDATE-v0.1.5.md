# Ippo to Read v0.1.5

## Left-click comic menu

Clicking a comic/shelf card in **Your shelves** now opens a small action menu instead of immediately navigating away.

The menu includes:

- **Open comic** — opens its chapter/volume shelf.
- **Start / Continue reading** — jumps straight into the current chapter.
- **Add comic cover** — choose your own JPG, PNG, WebP, or GIF cover image.
- **Use chapter cover** — removes the custom image and returns to the automatic chapter cover.

The custom cover is copied into Ippo's managed storage. Once Ippo confirms it was saved, the source image can be deleted from Desktop, Downloads, or wherever it was selected from.

Private-library custom covers continue to use the encrypted private cover storage introduced in v0.1.4.

## Existing shelf detail control

The shelf detail button is now named **Add / change comic cover** so the same feature is easy to understand from either screen.
