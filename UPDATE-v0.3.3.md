# Ippo to Read v0.3.3

## Future-updates roadmap

- Adds a small `!` button to the sidebar.
- Clicking it opens a read-only **Possible future updates** panel.
- The roadmap currently lists:
  - third-party library connections (ComicK, MyAnimeList and similar trackers),
  - better metadata reading,
  - external downloads directly into Ippo,
  - multiple UI layouts,
  - an Android version.
- Every item is clearly marked **Planned** so users do not mistake roadmap concepts for current features.
- The panel performs no network requests and changes no library data.
